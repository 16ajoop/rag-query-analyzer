2. langchain-core 
	 this is the core foundation underneath LangChain. 
   It contains important abstractions such as  	"" ChatPromptTemplate "" and the LCEL pipeline syntax "" prompt | llm "".

   An LCEL pipeline (LangChain Expression Language pipeline) is a declarative way
   to link AI and Large Language Model (LLM) components together using a pipe operator (|), much like a Unix  comand-line pipeline.
	-  the pipe operator inspired by unix command-line pipes, it takes the output from the component on the left and automatically feeds it as input to the component
           on the right.

	- A standard text generation pipeline looks like this: chain = prompt | model | output_parser

3. langchain-ollama 
	this one is specifically for connecting LangChain to ollama.

4. langgraph 
	allows you to build workflows where different nodes perform different tasks.
   my RAG system can look like:

                    START
                      ↓
                Query Analyzer
                      ↓
              Query Router
                 ↙       ↘
        Query Expansion   Decomposition
                 ↘       ↙
                  Retrieval
                      ↓
                    RRF
                      ↓
                  Reranker
                      ↓
                Generation
                      ↓
                     END
    LangChain = tools
    LangGraph = workflow/orchestration


5. Literal 
	Allows you to specify exact allowed values.

6. Pydantic  
	Acts as a validator for python data.

   eg age : int ------- age must be an integer
   eg intent:
	Literal[
    	"factual",
    	"explanation",
    	"comparison",  ...]      ------------ Intent must be one of these specific values.
 
  - I'm creating my own pydantic model called QueryAnalysis
  - Inside QueryAnalysis I am passing BaseModel which I imported from pydantic
  - BaseModel is like the foundation/rule system that my class follows in Pydantic.
    (- Think the BaseModel is like a application form , and pydantic is a person who checks whether the form is filled correctly or not.)
  - BaseModel itself does not contain all the rules, its a place were I can build custom rules

7. python-dotenv

  it contains information regarding my api key's or the model configurations.
